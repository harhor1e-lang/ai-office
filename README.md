# ALI AI COMPANY — Virtual Office

واجهة أولية لمقر شركة افتراضي، باللغة العربية، مع مخطط علوي تفاعلي وفريق من 15 موظفاً افتراضياً.

## التشغيل
- افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.
- لا توجد مكتبات خارجية مطلوبة.

## تنبيه مهم
هذه النسخة تعرض حركة وحالات محاكاة داخل المتصفح فقط. لا يوجد حتى الآن اتصال بنماذج ذكاء اصطناعي أو تنفيذ حقيقي للمهام أو تخزين مركزي.

## الخطوات القادمة
1. تصميم أقسام وطوابق أكثر تفصيلاً.
2. إضافة خادم خلفي آمن لإدارة المهام.
3. ربط الوكلاء بمزودات الذكاء الاصطناعي مع مفاتيح محفوظة على الخادم.
4. سجل مهام حقيقي وصلاحيات للمدير.
